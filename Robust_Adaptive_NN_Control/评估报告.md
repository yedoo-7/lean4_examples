# 评估报告：《未知离散非线性系统的鲁棒自适应 NN 控制》（李靖、李俊民，2003）

## 1. 论文内容概述

- **对象**：一类未知时变非线性离散严格反馈系统（式(1)）。
- **方法**：用小波神经网络(WNN/类 RBF)逼近未知非线性函数 αᵢ（式(2)），
  把系统转化为参数化严格反馈系统（式(3)）；再用 backstepping 逐步设计
  一个**避免过参数化**的自适应控制器（式(13)）与权值自适应律（式(15)）。
- **闭环结构**：误差系统最终写成线性时变递推（式(18)）
  `z(t+1) = A z(t) + b·y_d(t+n) + Σ(t+1) + e(t+1)`，
  其中 `A` 是严格稳定多项式 `F(q⁻¹)=1+f_n q⁻¹+…+f₁q⁻ⁿ` 的 companion（友）矩阵，
  故 Schur 稳定；其余项为有界的"不确定性/扰动"。
- **主结果（定理1）**：在假设 H1–H4 下存在常数 `ε*`、`εw*`，对 `ε∈[0,ε*]`、`εw∈[0,εw*]`
  闭环状态 `‖z(t)‖` 全局有界，且平均跟踪误差落入一个**大小与不确定性幅度成比例**的紧集（式(20)）。
- 最后给出 Σ₁、Σ₂ 两个数值仿真。

## 2. 能否在 Lean 4 中形式化？

**结论：可以，但分层次。**

| 部分 | 可形式化性 | 说明 |
|---|---|---|
| 系统模型(1)、转化后系统(3) | 容易 | 纯定义，可直接写成 Lean 递推 |
| 闭环线性误差系统(18)的稳定性内核 | **已完成（见下）** | 这是定理1结论真正的数学心脏 |
| companion 矩阵 Schur 稳定 ⇒ ‖Aᵏ‖ 几何衰减 | 中等 | 需谱半径/Gelfand 公式或构造合适范数；Mathlib 有相关工具 |
| WNN 万能逼近定理(式(2)所引文[7]) | 困难 | Mathlib 暂无现成的神经网络万能逼近定理，需从零构建 |
| backstepping 各步递推(式(4)–(17))的完整代数 | 工作量大 | 逐步代入、下标重排，工程量大但原则上可做 |
| 定理1完整证明（含 ε*、εw* 的存在性估计） | 很大 | 是一个大型形式化工程 |

**判断**：整篇论文"忠实、完整"形式化是一个**大型工程**，主要难点在于
(a) 神经网络万能逼近定理在 Mathlib 中缺失；(b) backstepping 多步递推代数繁琐；
(c) 论文对 `ε*`、`εw*` 只给存在性、未给显式值，需要补全估计细节。
但其**数学内核**——"Schur 稳定闭环 + 有界扰动 ⇒ 状态有界且误差与不确定性成比例"——
是干净、可证、并且已经在本项目中完整形式化并通过 Lean 内核校验（无 `sorry`，仅用标准公理）。

## 3. 已完成的形式化（`RequestProject/Main.lean`）

把误差系统(18)抽象为赋范空间中的压缩线性系统
`z(t+1) = A z(t) + w(t)`，其中 `‖A‖ ≤ ρ < 1`（Schur 稳定的算子范数刻画），
`‖w(t)‖ ≤ M`（不确定性幅度）。证明了：

1. `recurrence_bound`：标量递推 `a(t+1) ≤ ρ·a(t)+M` ⇒ `a(t) ≤ ρᵗ·a(0)+M/(1-ρ)`。
2. `recurrence_uniform_bound`：一致界 `a(t) ≤ a(0)+M/(1-ρ)`。
3. `linear_system_iss`：`‖z(t)‖ ≤ ρᵗ·‖z(0)‖ + M/(1-ρ)`（离散 ISS 估计）。
4. `closed_loop_globally_bounded`：**定理1(i) 内核**——状态全局有界，`∃B, ∀t, ‖z(t)‖ ≤ B`。
5. `tracking_error_proportional`：**定理1(ii) 内核**——渐近界为 `M/(1-ρ)`，
   对任意 `ε>0` 终将进入 `M/(1-ρ)+ε`；该界与不确定性幅度 `M` 成正比，`M=0` 时收敛到 0。

这两条恰好对应定理1的两个论断："全局有界"与"跟踪误差落入与不确定性成比例的紧集"。

## 4. 论文中发现的问题 / 不严谨之处

> 说明：原 PDF 为多栏排版、公式 OCR 严重错乱，下列前两条基于可清晰辨认的文字；
> 涉及具体公式下标处带有不确定性，已注明。

1. **假设编号重复（确凿的笔误）**：正文中"H3"出现了两次——
   一次是对建模误差/外扰 `μᵢ` 的界（H3），紧接着又有一个"H3"是对基函数 `Ψᵢ` 的两条条件。
   而定理1明确引用"假定 H1–H4"。可见第二个"H3"应为 **H4**，属编号笔误。
2. **逼近的紧集/半全局性循环**（常见的方法论隐患）：式(2)的 WNN 万能逼近只在紧集 `Ω_x` 上成立，
   依赖"状态 `x_t∈Ω_x`"这一前提；而状态有界本身又是要证明的结论。
   这类自适应/神经网络控制证明普遍存在"需有界以保证逼近、需逼近以证明有界"的半全局(semiglobal)循环，
   严格化时必须显式处理（例如先假定停留在紧集，或证明不变集）。论文未对此细节展开。
3. **跟踪误差界(20)的形式需复核**：OCR 还原的式(20)平均跟踪误差右端形如
   `β1 + β2·O(ε*,εw*)·(t-t0)/(K d)`，含 `(t-t0)` 因子。若该因子未被左端的平均（`1/N` 归一化）
   恰当抵消，则界会随时间增长而失去意义。由于公式 OCR 不可靠，**无法据此断定是错误**，
   但建议对照原始清晰版本核对(20)的归一化与 `(t-t0)` 的去向。
4. **`ε*`、`εw*` 仅给存在性**：论文（如其自述，"同其他鲁棒性讨论一样不给出具体值"）
   只断言稳定裕量常数存在，未给可计算表达式。这在工程论文中常见、可接受，
   但若要完整形式化，需要补全这些常数的显式构造与估计。

综上：论文主线**方法正确、结论合理**，未发现实质性的数学错误；
发现的问题主要是 (1) 一处假设编号笔误，(2) 半全局逼近的循环论证细节未展开，
(3) 个别公式需对照清晰原文复核（受 OCR 限制）。
